# 果园水彩插画资产登记

## 使用规则

- 本批插画均在 2026-09-05 使用 OpenAI ImageGen 按项目 UI 参考图重新生成，不包含第三方素材或图库元素。
- `design-assets/source` 保存项目内母版；`miniprogram/assets/orchard` 为小程序 512 px 长边版本；`admin-web/src/assets/orchard` 为后台 768 px 长边版本。
- 果树及分组共育图使用透明底；页面状态图使用与设计令牌一致的暖纸色背景，避免透明生成产生伪棋盘格。
- 仅用于本项目产品、演示和商业化开发；对外授权范围应在正式发布前由项目方统一确认。
