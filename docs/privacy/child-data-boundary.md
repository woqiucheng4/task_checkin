# 儿童数据与权限边界

> 适用版本：成长果园业务平台 0.1
>
> 更新日期：2026-09-05

本文定义产品当前代码必须遵守的数据隔离、访问、留存和治理边界。它是工程安全基线，不替代上线地区所需的隐私政策、儿童个人信息保护规则评审或法律意见。

## 1. 数据主体和空间

- 平台内部用全局 `childId` 连接孩子的个人任务、阳光、果树、水果和家庭愿望。
- 家庭与学校/辅导机构是彼此平行的一级空间，不存在机构管理家庭的关系。
- 每个机构只接触本机构生成的 `organizationMemberId`，业务 ViewModel 不向机构返回 `childId`。
- 一个孩子加入多个机构时，每个机构取得不同的成员编号；机构之间不能据此关联同一孩子。
- 家长可查看自己有效监护关系下孩子的全部来源任务；机构只可查看本机构产生的任务、提交和学习记录。

## 2. 最小数据清单

| 数据类型 | 主要用途 | 默认可见方 | 关键限制 |
|---|---|---|---|
| 微信运行时身份 | 登录和账号绑定 | 云函数服务端 | 客户端传入的 `openId` 不可信；日志不得输出完整值 |
| 孩子基础资料 | 家庭管理、机构内识别 | 有效监护人；获授权机构角色 | 机构仅见家长同意披露的昵称/姓名、年级、学号、头像字段 |
| 监护和同意记录 | 证明授权范围和变更 | 家庭；受控治理流程 | 同意与撤销记录只追加，不覆盖历史 |
| 家庭任务与愿望 | 家庭成长协作 | 有效家庭成员 | 教师、机构和内容方不可见 |
| 机构任务与提交 | 教学协作和审核 | 有权教师/助教、对应孩子与监护人 | 限定机构和分组范围，不得跨机构查询 |
| 阳光、果树和水果 | 孩子个人成长记录 | 孩子与有效监护人 | 不向机构暴露完整个人果园；阳光不可为负、交易或追回 |
| 分组共育进度 | 展示集体成果 | 有效分组成员和管理角色 | 孩子端不显示个人贡献、未完成名单或排名 |
| 照片和作业证据 | 任务识别与完成证明 | 资产声明的空间和角色 | 必须有保存期限、访问范围和删除状态；OCR 只生成草稿 |
| 审计、导出和客服授权 | 安全治理与问题处理 | 最小权限运营人员 | 儿童正文默认不可读；例外访问须绑定工单、范围和过期时间 |

## 3. 身份与授权边界

所有业务访问统一经过 `coreApi` 云函数。服务端使用运行时 `OPENID` 查找平台账号，再根据当前角色、租户关系、分组绑定、监护关系和家长同意共同鉴权。页面隐藏按钮不构成权限控制。

### 家庭访问

- 只有状态有效的监护关系可以选择孩子身份或管理其家庭资产。
- 家长不能更改教师发布的原始任务、教师学习评价或机构成员关系。
- 家庭愿望、奖励配置和家庭任务不向机构、教师或第三方内容方开放。

### 机构访问

- 教师/助教只在明确绑定的分组内操作；机构管理员只在所属机构内管理。
- 机构侧通过 `organizationMemberId` 读取孩子投影，拒绝用全局 `childId` 直接查询。
- 入组必须由家长领取有效邀请并确认披露范围，再由有权限的教师或助教批准。
- 家长撤销授权后，立即停止新任务分发和分组页面访问；机构历史统计按保留策略匿名化。
- 退出机构不会删除或回退个人阳光、果树、水果和家庭愿望。

### 平台与第三方访问

- 平台运营身份只能由部署环境的可信配置授予，不能由客户端 actor 字段声明。
- 客服默认不能读取儿童任务正文或媒体；临时读取须有有效工单、精确资源范围、过期时间和审计记录。
- 第三方内容方只能管理自己的模板和工作区，默认不能取得儿童账号、任务、提交、照片、果园或愿望数据。

## 4. 媒体、留存与删除

- 上传前先创建受控上传意图；完成后记录所属空间、所有者、可见角色、存储键、状态和过期时间。
- 作业证据的读取必须同时满足资产可见范围和当前有效成员关系。
- 到期清理先由业务规则筛出可删除资产，再调用存储适配器删除对象并记录删除状态；不允许客户端直接指定任意存储键。
- OCR 结果始终进入可编辑草稿。成人确认标题、内容、日期、学科、提交方式和目标范围后，才可发布任务。
- 正式保存期限由上线前的产品和合规评审确定；当前代码通过每个资产的 `expiresAt` 执行可配置期限，而非写死政策。

## 5. 导出、撤销和数据请求

- 家长应有查看当前授权、撤销机构授权、申请家庭数据导出和发起删除请求的入口。
- 机构导出必须包含申请人、租户范围、用途、审批人、状态和下载留痕；未审批时不能生成可下载结果。
- 删除请求不得通过改写只追加流水来伪造。阳光、审核、同意和审计类历史记录如因法定义务需保留，应采用去标识化、访问封存或新补偿记录表达。
- 当前代码实现了授权撤销、审批式导出和媒体到期删除；最终隐私页面、删除工单流和实际导出文件生成属于部署/管理端接入项。

## 6. 日志和密钥

日志不得记录以下内容：

- 完整 `openId`、孩子姓名和完整资料；
- PIN、邀请码明文、认领码明文；
- 任务/愿望正文、OCR 原文、照片下载地址或完整请求体；
- CloudBase 环境密钥、存储凭据或平台运营白名单。

业务错误通过稳定错误码和面向用户的安全消息返回；未知异常不得把堆栈、数据库语句或凭据传给小程序。生产日志脱敏需在实际云函数环境再次验证。

## 7. 明确禁止

- 未经家长同意由机构直接绑定孩子完整账号；
- 教师读取家庭任务、家庭奖励、愿望或其他机构数据；
- 公开孩子排名、未完成名单、个人贡献或跨组比较；
- 儿童聊天、评论、点赞、公开动态和广告画像；
- 购买、转让、现金兑换、惩罚性扣除或追回已获得阳光；
- 第三方直接读取儿童原始数据；
- 小程序端直连并修改账本、果树进度、成员关系或审计集合。

## 8. 工程控制与验证证据

- 41 个业务集合默认仅允许云函数服务端访问；只追加集合禁止更新和删除。
- 命令路由采用固定动作白名单，写命令要求非空 `requestId` 并保存回执。
- 任务提交、审核、阳光发放、个人果树和分组贡献分别有幂等键或事务边界。
- 自动化测试覆盖跨租户拒绝、机构投影隐藏 `childId`、监护权限、邀请同意、撤销后拒绝访问、愿望隔离、分组隐私、媒体访问、客服授权、导出审批和第三方隔离。
- 本地测试不能替代 CloudBase 安全规则、真实并发、日志、微信真机和实际存储服务验证；上线前按发布手册逐项执行。

验证结果和未执行项见[业务验收用例报告](../verification/2026-09-06-business-cases.md)。
