# 律果｜儿童成长打卡小程序

“律果”寓意自律结果实。该仓库当前存放产品规划与第一版实施计划；尚未创建小程序业务代码。

## 产品核心

家长设置每日小任务，孩子完成后打卡，家长审核发放积分，孩子用积分兑换愿望。

`任务设置 → 孩子打卡 → 家长确认 → 积分入账 → 愿望兑换`

## 当前固定决策

- 第一版：原生微信小程序 + 微信云开发 CloudBase。
- 运营：公司主体订阅号，内容推广并关联小程序。
- 暂不纳入第一版：教师/机构、分组、附件、管理后台、导出、AI、支付、独立 App、独立服务器与自有域名接入。
